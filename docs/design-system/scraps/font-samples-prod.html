Production font candidates

Patrick Hand and Special Elite are technically available on Google Fonts, but they're decorative display faces designed for posters and headlines — they don't hold up at 11–13px for UI labels, table cells, or form inputs. The two alternatives below capture the same personality with proper weight range, screen-tuned hinting, and tested production legibility. Each pair shows the wireframe font on the left and the production alternative on the right at the same content.

Handwriting / clubhouse Patrick Hand Kalam 3 weights, printed (not cursive). Best for hero headlines + pull quotes; legible at 13px+ for body too.

Primary UI (body + numbers) — Manrope Stays as is. Don't replace.
Headlines + display — Chivo Stays as is. Don't replace.

Why Kalam reads better than Caveat: Caveat is a flowing cursive (letters connect with strokes between them, italic-leaning), which gets harder to parse as the size drops. Kalam is a print handwriting — each letter stands alone, just like Patrick Hand — so it stays scannable at body sizes.
